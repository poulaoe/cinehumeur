# Installation rapide

1. Remplace le contenu de `cinehumeur_final` par ce dossier.
2. Garde le Root Directory Vercel sur `cinehumeur_final`.
3. Vérifie `SUPABASE_URL`, `SUPABASE_ANON_KEY` et `TMDB_READ_TOKEN`.
4. Commit sur GitHub puis laisse Vercel redéployer.
5. Teste `/api/config`, Google, puis le choix d’une humeur.

Cette version garde Supabase et centre l’expérience sur l’humeur.
